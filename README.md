AI, NOUE(仮)
Dlab Digital Factoryのスタッフ井上さんの知能の一部を共有したAIを常駐させ、初めての来訪者や基礎的な質問への対応を任せることで、井上さん本人がテクニカルな相談・プロジェクトベースの相談に時間を割けるようにするプロジェクト。
これは何か
このリポジトリの index.html は、会話ロジック(第1レイヤー)だけを検証するための最小プロトタイプです。GitHub Pagesで公開しており、ブラウザで開くだけでチャットが動きます。

公開URL: https://ayno0313.github.io/AI-NOUE/ (Settings > Pages 有効化後に発行)

現状のステータス(重要)
回答内容はすべてダミーです。 レーザーカッターの予約方法や3Dプリンタの説明などは、実際のDlabマニュアルやアーカイブに基づいていません。会話の流れと「基礎質問 vs 井上さんに回すべき相談」の判定ロジックを試すための仮データです。内容の正確さは検証していません。
声・見た目もダミーです。 音声はブラウザ標準の音声合成(汎用ボイス)、アバターは汎用の丸顔SVGです。井上さんご本人の声・姿は使用していません。
井上さんへは企画の概要を説明済みで好意的な反応をもらっていますが、声のクローンや見た目の再現について、使用範囲を明記した個別の同意はまだ取れていません。声クローン(ElevenLabs等)やBlenderアバターの実装は、この同意が取れてから着手します。

技術構成
単一の index.html のみ。外部サーバー・ビルド・依存パッケージなし。ブラウザの SpeechSynthesis API(標準機能)で読み上げ、質問文とキーワードのマッチングで回答を返す簡易ロジックです。RAGや外部LLM APIへの接続はまだ組み込んでいません。

次にやること
井上さんからファクトリーのマニュアル・過去PJアーカイブ(録画/文字起こし)を受け取る
受け取ったデータをもとに index.html 内の KB(質問と回答のセット)を実データベースの内容に差し替える
アーカイブの量が数十〜数百件規模になった場合、キーワードマッチ方式では限界が来るため、検索(RAG)方式への切り替えを検討する
声クローン・Blenderアバターは、井上さんご本人と使用範囲の同意を書面か議事録で取ってから着手する
